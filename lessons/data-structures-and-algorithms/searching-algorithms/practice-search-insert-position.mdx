## Try It Yourself

Use the editor below to find the first index whose value is greater than or equal to the target. Return that position, or the array length if every value is smaller. When the target is absent, the result is where it belongs in ascending order.

Submit your implementation when it passes the examples. Test targets before the first value, after the last value, and between two values.

## Solution

Treat the right boundary as one position past the array. When the middle value is smaller than the target, discard it and everything to its left. Otherwise, keep the middle position as a possible answer and move the right boundary to it.

When the boundaries meet, that position is the lower bound for the target. In the diagram, index `1` holds the first `4`. To insert `5`, use index `4`, immediately before `9`. The same rule works whether the input contains duplicates or, as in this exercise, only distinct values.

![In the sorted array 2, 4, 4, 4, 9, target 4 belongs at index 1 and target 5 belongs at index 4.](https://pub-d143c03df8bc45d5a4589bc793aa52e4.r2.dev/courses/bf48d3e5-37f4-44d4-bbd6-8d8635d1163b/gallery/f8c8830b-a2cf-46c4-9615-a559b2298f73)

<Tabs items={["JavaScript", "Python"]}>
  <Tab value="JavaScript">
    ```js
    function searchInsert(nums, target) {
      let left = 0;
      let right = nums.length;
    
      while (left < right) {
        const middle = left + Math.floor((right - left) / 2);
    
        if (nums[middle] < target) left = middle + 1;
        else right = middle;
      }
    
      return left;
    }
    ```
  </Tab>
  <Tab value="Python">
    ```python
    def search_insert(nums, target):
        left = 0
        right = len(nums)
    
        while left < right:
            middle = left + (right - left) // 2
    
            if nums[middle] < target:
                left = middle + 1
            else:
                right = middle
    
        return left
    ```
  </Tab>

### Big O notation

| Measure | Complexity | Explanation |
|---|---:|---|
| Time | `O(log n)` | Every comparison removes about half of the remaining positions. |
| Auxiliary space | `O(1)` | Only the search boundaries and middle index are stored. |
