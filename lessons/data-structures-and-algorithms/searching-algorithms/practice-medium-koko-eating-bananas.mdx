## Solution

Possible speeds form an ordered range from 1 through the largest pile. The deadline allows at least one hour per pile, so the largest pile is a feasible upper bound. A candidate is feasible when the sum of each pile's rounded-up division by that speed is no more than h.

For piles `[3, 6, 7, 11]` and an eight-hour deadline, speed `3` takes ten hours and speed `4` takes eight. A slower speed can only take longer.

![For piles 3, 6, 7 and 11, speed 3 takes ten hours and speed 4 meets the eight-hour limit.](https://pub-d143c03df8bc45d5a4589bc793aa52e4.r2.dev/courses/de621dcc-8566-41ff-9cec-9dc15fd3ff39/gallery/5716122f-302b-4cfb-b124-57d73d67d55f)

If a speed is feasible, keep it as a possible answer and search lower speeds. Otherwise, discard it and every slower speed.

<Tabs items={["JavaScript", "Python"]}>
  <Tab value="JavaScript">
    ```js
    function minEatingSpeed(piles, h) {
      let left = 1;
      let right = 1;
      for (const pile of piles) right = Math.max(right, pile);
    
      while (left < right) {
        const speed = left + Math.floor((right - left) / 2);
        let hours = 0;
    
        for (const pile of piles) {
          hours += Math.ceil(pile / speed);
        }
    
        if (hours <= h) right = speed;
        else left = speed + 1;
      }
    
      return left;
    }
    ```
  </Tab>
  <Tab value="Python">
    ```python
    def min_eating_speed(piles, h):
        left = 1
        right = max(piles)
    
        while left < right:
            speed = left + (right - left) // 2
            hours = 0
    
            for pile in piles:
                hours += (pile + speed - 1) // speed
    
            if hours <= h:
                right = speed
            else:
                left = speed + 1
    
        return left
    ```

### Big O notation

| Measure | Complexity | Explanation |
|---|---:|---|
| Time | `O(n log(m + 1))` | Finding the maximum takes one scan. Each subsequent candidate check also scans all n piles, where m is the largest pile. |
| Auxiliary space | `O(1)` | Only search boundaries and the current hour total are stored. |
