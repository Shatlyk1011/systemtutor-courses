## Solution

The original array was strictly increasing, so it has distinct values and at most one drop after rotation. At least one half around the middle is sorted. On `[4, 5, 6, 7, 0, 1, 2]`, the middle is `7` and the left half runs from `4` through `7`. Target `0` falls outside those bounds, so the next range starts immediately after `7`.

![At middle value 7, the sorted left half spans values 4 to 7. Target 0 falls outside it, so keep indices 4 through 6.](https://pub-d143c03df8bc45d5a4589bc793aa52e4.r2.dev/courses/ba5422b9-c8ef-4672-b067-9c87b70f4f60/gallery/e2fc28aa-11bf-4c65-a433-b53f57167c50)

This decision preserves binary search's ability to discard half of the remaining array after every comparison.

<Tabs items={["JavaScript", "Python"]}>
  <Tab value="JavaScript">
    ```js
    function searchRotated(nums, target) {
      let left = 0;
      let right = nums.length - 1;
    
      while (left <= right) {
        const middle = left + Math.floor((right - left) / 2);
        if (nums[middle] === target) return middle;
    
        if (nums[left] <= nums[middle]) {
          if (nums[left] <= target && target < nums[middle]) {
            right = middle - 1;
          } else {
            left = middle + 1;
          }
        } else if (nums[middle] < target && target <= nums[right]) {
          left = middle + 1;
        } else {
          right = middle - 1;
        }
      }
    
      return -1;
    }
    ```
  </Tab>
  <Tab value="Python">
    ```python
    def search_rotated(nums, target):
        left = 0
        right = len(nums) - 1
    
        while left <= right:
            middle = left + (right - left) // 2
            if nums[middle] == target:
                return middle
    
            if nums[left] <= nums[middle]:
                if nums[left] <= target < nums[middle]:
                    right = middle - 1
                else:
                    left = middle + 1
            elif nums[middle] < target <= nums[right]:
                left = middle + 1
            else:
                right = middle - 1
    
        return -1
    ```
  </Tab>
</Tabs>

### Big O notation

| Measure | Complexity | Explanation |
|---|---:|---|
| Time | `O(log n)` | A sorted-half check discards half of the remaining array each iteration. |
| Auxiliary space | `O(1)` | The search stores only three indices. |
