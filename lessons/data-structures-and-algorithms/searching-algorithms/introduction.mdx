A search chooses which candidate to inspect next. On the array `[8, 3, 6, 3]`, “does 3 occur?”, “where is its first occurrence?”, and “how many times does it occur?” all examine the same data. Their answers are `true`, index `1`, and `2`.

## What is a searching algorithm?

Start by specifying the result. A membership check can stop at the first match. A count has to account for every match. An insertion position is useful even when a match is missing.

## Common searching tasks

| Task | What to return |
|---|---|
| Find a substring | The starting position of the first match, or a missing-value marker |
| Check a username | Whether the name is already in the collection |
| Find the first failing version | The earliest version that fails a check |
| Count qualifying array values | The number of entries satisfying a condition |

## Choosing a search

Ask what a failed check tells you about the remaining candidates. In an unsorted array, seeing `8` tells you nothing about where `3` might be. In an ascending array, if the middle value exceeds `3`, everything to its right also exceeds `3`. That guarantee lets one comparison eliminate many candidates.

## Chapter flow

- [Linear Search](/courses/data-structures-and-algorithms/docs/searching-algorithms/linear-search): Check unsorted values one at a time.
- [Binary Search](/courses/data-structures-and-algorithms/docs/searching-algorithms/binary-search): Repeatedly eliminate half of a sorted array.
- [Binary Search Boundaries](/courses/data-structures-and-algorithms/docs/searching-algorithms/binary-search-boundaries): Find the first or last matching position.
- [Binary Search on the Answer](/courses/data-structures-and-algorithms/docs/searching-algorithms/binary-search-on-the-answer): Search a range of possible answers with a monotonic condition.
