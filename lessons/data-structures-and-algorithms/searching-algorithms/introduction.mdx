## What is a searching algorithm?

![Searching in different contexts](https://pub-d143c03df8bc45d5a4589bc793aa52e4.r2.dev/courses/3cf2b7c0-b4e3-4aa7-8dbf-f3dfb8f1f738/gallery/45b5935a-724d-40c3-b321-0e63bbccfc70)

A searching algorithm is a reusable solution for finding or checking information. Searching can describe simple lookup tasks or more complex systems such as Google.

## Common searching tasks

| Task | What is being searched or checked? |
|---|---|
| Find a substring | Whether one piece of text appears inside another |
| Check a username | Whether a username is already taken |
| Validate a state | Whether a state is valid |
| Locate an array value | Where a value appears in an array |

These tasks look different, but each requires a way to find information or determine whether a condition is true.

## A useful way to think about named algorithms

Algorithm names describe reusable solutions to common problems. When a problem involves searching, the appropriate searching algorithm provides a structured way to solve it.

<Callout title="Key idea" type="info">
Searching is not limited to finding a value in an array. It also includes checking text, usernames, and valid states, as well as supporting complex systems such as Google.
</Callout>

## Chapter flow

- [Linear Search](/courses/data-structures-and-algorithms/docs/searching-algorithms/linear-search): Check unsorted values one at a time.
- [Binary Search](/courses/data-structures-and-algorithms/docs/searching-algorithms/binary-search): Repeatedly eliminate half of a sorted array.
- [Binary Search Boundaries](/courses/data-structures-and-algorithms/docs/searching-algorithms/binary-search-boundaries): Find the first or last matching position.
- [Binary Search on the Answer](/courses/data-structures-and-algorithms/docs/searching-algorithms/binary-search-on-the-answer): Search a range of possible answers with a monotonic condition.
