Data structures and algorithms help you organize data and solve problems efficiently. Start by comparing solutions, then build the structures and patterns you need to solve problems.

## Course roadmap

- [Big O notation](/courses/data-structures-and-algorithms/docs/big-o-notation/algorithm-performance): See why two correct solutions can use different amounts of time and memory.
- [Built-in data structures](/courses/data-structures-and-algorithms/docs/arrays-strings-and-hash-maps/introduction): Learn how data structures organize data before working with arrays, strings, hash maps, and sets.
- [Algorithm patterns](/courses/data-structures-and-algorithms/docs/algorithm-patterns/introduction): Recognize when frequency counters, two pointers, or sliding windows fit a problem.
- [Linked lists, stacks, and queues](/courses/data-structures-and-algorithms/docs/data-structures/single-linked-list): Start with singly linked lists, then study stacks and queues.
- [Recursion](/courses/data-structures-and-algorithms/docs/recursion/introduction): Break a problem into smaller calls that stop at a base case.
- [Sorting](/courses/data-structures-and-algorithms/docs/sorting-algorithms/introduction): Learn how sorting orders data and how comparison rules control that order.
- [Searching](/courses/data-structures-and-algorithms/docs/searching-algorithms/introduction): Start with common lookup tasks, then move into linear and binary search.

Use the quizzes and practice problems available in each chapter to apply what you learn, such as [Two Sum](/courses/data-structures-and-algorithms/docs/algorithm-patterns/practice-two-sum).
