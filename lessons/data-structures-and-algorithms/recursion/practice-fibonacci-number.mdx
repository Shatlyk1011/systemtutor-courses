## Try It Yourself

Use the editor below to compute the `n`th Fibonacci number.

<Callout title="Memoize recursive results" type="info">

</Callout>

## Solution

The base cases return 0 and 1 immediately. Every larger Fibonacci number is the sum of the two smaller Fibonacci calls before it.

Computing `F(4)` first takes the `F(3)` branch. That branch computes `F(2) = 1` and saves it. When `F(4)` next asks directly for `F(2)`, the lookup returns `1` immediately. The two branches now give `F(4) = 2 + 1 = 3`.

![While computing F(4), the F(3) branch saves F(2). The later request for F(2) reuses that result.](https://pub-d143c03df8bc45d5a4589bc793aa52e4.r2.dev/courses/ba5422b9-c8ef-4672-b067-9c87b70f4f60/gallery/f3301a09-a93c-40f3-818e-a746df48dae1)

<Tabs items={["JavaScript", "Python"]}>
  <Tab value="JavaScript">
    ```js
    function fib(n) {
      const memo = new Map();
    
      function calculate(value) {
        if (value <= 1) return value;
        if (memo.has(value)) return memo.get(value);
    
        const result = calculate(value - 1) + calculate(value - 2);
        memo.set(value, result);
        return result;
      }
    
      return calculate(n);
    }
    ```
  </Tab>
  <Tab value="Python">
    ```python
    def fib(n):
        memo = {}
    
        def calculate(value):
            if value <= 1:
                return value
            if value in memo:
                return memo[value]
    
            result = calculate(value - 1) + calculate(value - 2)
            memo[value] = result
            return result
    
        return calculate(n)
    ```
  </Tab>
</Tabs>

### Big O notation

| Measure | Complexity | Explanation |
|---|---:|---|
| Time | `O(n)` | Each non-base value is computed once. Subsequent calls for that value use a lookup. |
| Auxiliary space | `O(n)` | The memo and recursive call stack can each grow with n. |
