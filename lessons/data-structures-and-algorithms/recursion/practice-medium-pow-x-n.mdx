## Solution

A zero exponent is the base case and returns 1. For larger exponents, recursively calculate the result for half the exponent and square that result.

Compute the half power once and reuse it in the square. For `2⁵`, the recursive call for exponent `2` returns `4`. Squaring gives `16`, then the odd exponent contributes one extra factor of `2`, giving `32`.

![Exponent 5 halves to 2, 1 and 0. On return the computed powers of 2 are 1, 2, 4 and 32.](https://pub-d143c03df8bc45d5a4589bc793aa52e4.r2.dev/courses/ba5422b9-c8ef-4672-b067-9c87b70f4f60/gallery/436eb77a-3603-481e-a257-949e3b197a29)

For a negative exponent, first use the reciprocal base and then work with the positive magnitude. This requires a nonzero base. For example, `2⁻³` becomes `(1/2)³`.

<Tabs items={["JavaScript", "Python"]}>
  <Tab value="JavaScript">
    ```js
    function myPow(x, n) {
      const base = n < 0 ? 1 / x : x;

      function power(exponent) {
        if (exponent === 0) return 1;
    
        const half = power(Math.floor(exponent / 2));
        const squared = half * half;
    
        return exponent % 2 === 0 ? squared : squared * base;
      }
    
      return power(Math.abs(n));
    }
    ```
  </Tab>
  <Tab value="Python">
    ```python
    def my_pow(x, n):
        base = 1 / x if n < 0 else x

        def power(exponent):
            if exponent == 0:
                return 1
    
            half = power(exponent // 2)
            squared = half * half
    
            return squared if exponent % 2 == 0 else squared * base
    
        return power(abs(n))
    ```
  </Tab>
</Tabs>

### Big O notation

| Measure | Complexity | Explanation |
|---|---:|---|
| Time | `O(log(1 + abs(n)))` | For a nonzero exponent, each call halves its magnitude. The zero case returns immediately. |
| Auxiliary space | `O(log(1 + abs(n)))` | For a nonzero exponent, the stack grows by one frame per halving step. The zero case takes constant space. |
