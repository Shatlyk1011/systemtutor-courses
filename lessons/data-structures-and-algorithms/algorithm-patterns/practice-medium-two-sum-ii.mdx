## Try It Yourself

Find the target pair in the sorted array. JavaScript and Python start array indices at `0`. The answer counts positions starting at `1`, so add `1` to each index when you return it.

<Callout title="Use constant extra space" type="info">
Find the pair with two pointers and `O(1)` extra space without building a lookup map. Use the array's sorted order to decide which pointer should move after each sum. Handle negative and duplicate values.
</Callout>

## Solution

![For target 13, 1 + 15 is too large, 1 + 11 is too small, and 2 + 11 matches.](https://pub-d143c03df8bc45d5a4589bc793aa52e4.r2.dev/courses/1e3e13b6-0db0-43d8-9eab-205bdcf6fa8f/gallery/844b79e4-d2d6-4e16-969c-f25d6d228cdc)

Start `left` at the first element and `right` at the last. If the sum is too small, even the largest remaining partner falls short for `numbers[left]`, so move `left` one step right. If the sum is too large, even the smallest remaining partner makes the sum too large for `numbers[right]`, so move `right` one step left.

In the figure, the values `2` and `11` match the target at zero-based indices `1` and `4`. They are the second and fifth elements, so `[left + 1, right + 1]` gives `[2, 5]`.

<Tabs items={["JavaScript", "Python"]}>
  <Tab value="JavaScript">
    ```js
    function twoSumSorted(numbers, target) {
      let left = 0;
      let right = numbers.length - 1;
    
      while (left < right) {
        const sum = numbers[left] + numbers[right];
    
        if (sum === target) return [left + 1, right + 1];
        if (sum < target) left++;
        else right--;
      }
    
      return [];
    }
    ```
  </Tab>
  <Tab value="Python">
    ```python
    def two_sum_sorted(numbers, target):
        left = 0
        right = len(numbers) - 1
    
        while left < right:
            total = numbers[left] + numbers[right]
    
            if total == target:
                return [left + 1, right + 1]
            if total < target:
                left += 1
            else:
                right -= 1
    
        return []
    ```
  </Tab>
</Tabs>

### Big O notation

| Measure | Complexity | Explanation |
|---|---:|---|
| Time | `O(n)` | Each check either returns the answer or moves one pointer inward. There are at most `n - 1` checks. |
| Auxiliary space | `O(1)` | Only two pointer indices and the current sum are stored. |
