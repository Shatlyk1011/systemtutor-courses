## Solution

![In abcab, the valid window changes from abc to bca to cab as a repeated character arrives.](https://pub-d143c03df8bc45d5a4589bc793aa52e4.r2.dev/courses/1e3e13b6-0db0-43d8-9eab-205bdcf6fa8f/gallery/a4de7c73-3a47-4932-bb3c-b14a0152b31c)

A set represents the characters currently inside the window. When the right character is already in the set, remove characters from the left until that duplicate is gone.

Add the new character and update the longest valid length. Every character in a valid window is distinct, so its set size equals its length. For `"abba"`, the second `b` requires removing both the old `a` and the old `b` before the new `b` can enter.

Both solutions count Unicode code points. JavaScript uses a second forward iterator to read the character leaving the left edge. An emoji that occupies two UTF-16 code units still enters and leaves as one code point.

<Tabs items={["JavaScript", "Python"]}>
  <Tab value="JavaScript">
    ```js
    function lengthOfLongestSubstring(s) {
      const window = new Set();
      const leftEdge = s[Symbol.iterator]();
      let longest = 0;

      for (const character of s) {
        while (window.has(character)) {
          window.delete(leftEdge.next().value);
        }
        window.add(character);
        longest = Math.max(longest, window.size);
      }

      return longest;
    }
    ```
  </Tab>
  <Tab value="Python">
    ```python
    def length_of_longest_substring(s):
        window = set()
        left = 0
        longest = 0
    
        for character in s:
            while character in window:
                window.remove(s[left])
                left += 1
    
            window.add(character)
            longest = max(longest, len(window))
    
        return longest
    ```
  </Tab>
</Tabs>

### Big O notation

| Measure | Complexity | Explanation |
|---|---:|---|
| Time | Average `O(n)` | Each character enters and leaves the window at most once. |
| Auxiliary space | `O(k)` | Here k is the maximum number of distinct characters in a valid window. |
