An **algorithm pattern** is a way of organizing work that applies to more than one problem. To choose a pattern, ask what information lets you safely skip work on the next step.

## Choose a pattern

Start with one string, `"ABBA"`. Counting letters gives the same answer even if the letters are rearranged. Checking for a palindrome requires comparing mirrored positions. Looking for adjacent repeats requires keeping a contiguous pair as it moves through `AB`, `BB`, and `BA`.

![Three patterns applied to ABBA. A frequency counter records two As and two Bs, inward pointers compare the two outside As, and a width-two window captures the adjacent Bs.](https://pub-d143c03df8bc45d5a4589bc793aa52e4.r2.dev/courses/ba5422b9-c8ef-4672-b067-9c87b70f4f60/gallery/033a4e77-13ba-4024-b1f8-412ff4bed920)

Now apply those choices to other inputs:

| Problem | What to keep | Why the next step is safe |
| --- | --- | --- |
| Do two words contain the same letters in the same quantities? | A count for each character | Consuming one count per letter accounts for every occurrence. |
| Which two values in a sorted array sum to a target? | The two ends of the remaining range | Ordering lets one comparison eliminate an entire endpoint. |
| Which consecutive four values have the largest sum? | A running sum and window bounds | Neighboring windows share three values, so only two edge values affect the update. |

Some problems combine patterns. For example, a sliding window can use a map to track the character counts within its current bounds.

## Chapter flow

Start with frequency counters, then move through two pointers and sliding windows:

1. **[Frequency Counters](/courses/data-structures-and-algorithms/docs/algorithm-patterns/hash-maps-and-frequency-counters):** Count items with hash maps to avoid nested loops.
2. **[Two Pointers](/courses/data-structures-and-algorithms/docs/algorithm-patterns/two-pointers):** Use ordering or symmetry to decide which position can move.
3. **[Sliding Window](/courses/data-structures-and-algorithms/docs/algorithm-patterns/sliding-window):** Track a moving window over an array or string.
