## Solution

![For heights 2, 5, 1, 4, the first pair holds 6 units. Replacing the shorter left wall raises the area to 8.](https://pub-d143c03df8bc45d5a4589bc793aa52e4.r2.dev/courses/ba5422b9-c8ef-4672-b067-9c87b70f4f60/gallery/7c82b018-30bd-4256-9d75-d0875baade1c)

Start with the widest possible container. Record its area, then move the pointer at the shorter line because keeping that shorter height cannot improve the area after the width shrinks.

For heights `[2, 5, 1, 4]`, the outside walls give `3 × 2 = 6`. Keeping the wall of height 2 would only narrow that container. Move left to height 5: the width is now 2 and the limiting height is 4, giving area 8. If the two endpoint heights tie, either one can be discarded after recording its area.

<Tabs items={["JavaScript", "Python"]}>
  <Tab value="JavaScript">
    ```js
    function maxArea(heights) {
      let left = 0;
      let right = heights.length - 1;
      let maximum = 0;
    
      while (left < right) {
        const width = right - left;
        const height = Math.min(heights[left], heights[right]);
        maximum = Math.max(maximum, width * height);
    
        if (heights[left] <= heights[right]) left++;
        else right--;
      }
    
      return maximum;
    }
    ```
  </Tab>
  <Tab value="Python">
    ```python
    def max_area(heights):
        left = 0
        right = len(heights) - 1
        maximum = 0
    
        while left < right:
            width = right - left
            height = min(heights[left], heights[right])
            maximum = max(maximum, width * height)
    
            if heights[left] <= heights[right]:
                left += 1
            else:
                right -= 1
    
        return maximum
    ```

### Big O notation

| Measure | Complexity | Explanation |
|---|---:|---|
| Time | `O(n)` | The two pointers move inward across the array once. |
| Auxiliary space | `O(1)` | The algorithm stores only pointer positions and the best area. |
