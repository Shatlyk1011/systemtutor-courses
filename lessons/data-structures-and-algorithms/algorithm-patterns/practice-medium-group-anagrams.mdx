## Solution

Build a 26-position frequency signature for each word. Anagrams produce the same signature even when their characters appear in a different order.

For the input `["eat", "bat", "tea"]`, compare four slots of the signature. Every unlisted slot is zero.

| Word | a | b | e | t |
| --- | ---: | ---: | ---: | ---: |
| `eat` | 1 | 0 | 1 | 1 |
| `bat` | 1 | 1 | 0 | 1 |
| `tea` | 1 | 0 | 1 | 1 |

Use the full signature as the map key. Create a group when a signature first appears. When the same signature returns, append the word to its existing group. This preserves both the group order and the order within each group.

<Tabs items={["JavaScript", "Python"]}>
  <Tab value="JavaScript">
    ```js
    function groupAnagrams(words) {
      const groups = new Map();
    
      for (const word of words) {
        const counts = Array(26).fill(0);
    
        for (const character of word) {
          counts[character.charCodeAt(0) - 97]++;
        }
    
        const signature = counts.join("#");
    
        if (!groups.has(signature)) {
          groups.set(signature, []);
        }
    
        groups.get(signature).push(word);
      }
    
      return Array.from(groups.values());
    }
    ```
  </Tab>
  <Tab value="Python">
    ```python
    def group_anagrams(words):
        groups = {}
    
        for word in words:
            counts = [0] * 26
    
            for character in word:
                counts[ord(character) - ord("a")] += 1
    
            signature = tuple(counts)
    
            if signature not in groups:
                groups[signature] = []
    
            groups[signature].append(word)
    
        return list(groups.values())
    ```

### Big O notation

Let `n` be the number of words, `L` their combined length and `g` the number of distinct groups. The alphabet has a fixed size of 26.

| Measure | Complexity | Explanation |
|---|---:|---|
| Time | `O(n + L)` average | Initialize the fixed-size counters for each word and visit every letter. Even an empty word needs a group lookup. |
| Returned groups | `O(n + g)` references | Each word appears once, in one group. The strings themselves are reused. |
| Auxiliary space | `O(g)` fixed-size count tuples in Python | JavaScript stores a serialized key per group. If measuring characters, count the combined length of those keys as well. |
