Sorting means rearranging the items in a collection according to a comparison. For numeric arrays, the comparison commonly determines whether the numbers should appear in **ascending** or **descending** order.

For example, sorting `[5, 2, 8]` from smallest to largest gives `[2, 5, 8]`. Reversing the comparison gives `[8, 5, 2]`. Both results contain the three original values.

---

## Why Sorting Matters

Ordering a class roster by surname makes it easier to look up students. Ordering the same roster by exam score answers a different question. The sorting **key** is the part of each record used for comparison.

What happens when keys are equal? Suppose the original roster lists A (score 2), B (score 1), C (score 2). A **stable sort** by ascending score gives B, A, C. A and C keep their original order within the tie. This matters when an earlier ordering, such as registration time, carries information.

When comparing algorithms, track how many comparisons and moves they make, how much additional memory they need, and whether ties preserve their input order.

## JavaScript Array Sort

JavaScript provides a built-in array `sort` method for ordering array elements.

### Default behavior

The method rearranges the original array in place. Its default order is **string order**. JavaScript converts array items to strings and compares their UTF-16 code units. This leads to unexpected results for numbers:

```js
const numbers = [6, 4, 15, 10];

numbers.sort();
console.log(numbers); // [10, 15, 4, 6] (because "1" comes before "4" in Unicode)
```

### Comparator functions

A comparator function `(a, b)` tells JavaScript how to order elements:

- Return `< 0`: `a` comes before `b`
- Return `> 0`: `b` comes before `a`
- Return `0`: `a` and `b` stay in their current relative order

Use the same input in both languages. For `[6, 4, 15, 10]`, which value should come first in numeric order? Which value comes first when the string representations are compared from left to right?

| Sort goal | JavaScript comparison | Python ordering |
|---|---|---|
| Numbers, ascending | `(a, b) => a - b` | Numeric values already compare in numeric order. |
| Numbers, descending | `(a, b) => b - a` | `reverse=True` reverses that order. |
| Words, shortest first | `(a, b) => a.length - b.length` | `key=len` uses the length of each word. |

### Code examples

Both examples sort the same numbers and words. In the length sort, `"cat"` and `"dog"` tie. Predict their relative order from the input.

<Tabs items={["JavaScript", "Python"]}>
  <Tab value="JavaScript">
    ```js
    const numbers = [6, 4, 15, 10];
    numbers.sort((a, b) => a - b);
    console.log(numbers); // [4, 6, 10, 15]

    numbers.sort((a, b) => b - a);
    console.log(numbers); // [15, 10, 6, 4]

    const words = ["elephant", "cat", "dog", "giraffe"];
    words.sort((a, b) => a.length - b.length);
    console.log(words); // ["cat", "dog", "giraffe", "elephant"]
    ```
  </Tab>
  <Tab value="Python">
    ```python
    numbers = [6, 4, 15, 10]
    numbers.sort()
    print(numbers)  # [4, 6, 10, 15]

    numbers.sort(reverse=True)
    print(numbers)  # [15, 10, 6, 4]

    words = ["elephant", "cat", "dog", "giraffe"]
    print(sorted(words, key=len))  # ['cat', 'dog', 'giraffe', 'elephant']
    ```
  </Tab>
</Tabs>

Python’s `list.sort()` updates the original list. Its `sorted()` function returns a new list, so `words` still has its original order in the Python example. Both languages use a stable built-in sort and preserve the order of the tied words.

## Key Takeaways

- **Rearranging Collections:** Sorting rearranges items in a collection according to a comparison rule.
- **Numeric Order:** Arrays are commonly sorted in ascending or descending order without altering their elements.
- **Stability:** Equal-key records retain their original relative order in a stable sort.
- **Algorithm Trade-offs:** Different sorting algorithms come with distinct strengths, limitations, time complexities, and memory usage.
- **Built-in sorting:** JavaScript needs a numeric comparator for numbers because its default compares string representations. Python sorts numbers numerically by default and accepts a `key` function for other orderings.
