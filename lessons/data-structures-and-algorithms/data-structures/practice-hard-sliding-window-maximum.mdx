## Try It Yourself

Return the maximum for each window of `k` consecutive elements. As the window moves one step, one value enters and another expires. A **deque** (double-ended queue) lets you remove candidates from either end.

Submit your implementation when it passes the examples. Remove indices that leave the window and values that can no longer become a maximum.

## Solution

![For windows containing 4, 2, 3 and then 2, 3, 1, the deque keeps the candidates 4, 3 and then 3, 1. Each first candidate is the window maximum.](https://pub-d143c03df8bc45d5a4589bc793aa52e4.r2.dev/courses/ba5422b9-c8ef-4672-b067-9c87b70f4f60/gallery/b2f6f8fb-308a-4c55-957c-4fd6a8f89796)

Store indices in increasing order from front to back. Their **values** must strictly decrease in that direction. With current index `i`, first remove indices at the front that are at most `i - k`. Next remove indices at the back whose values are at most `nums[i]`. The newer value is at least as large and stays in the window longer. Append `i`. Once the window is full, read the value at the front index.

For `[4, 2, 3, 1]` with `k = 3`, the arrival of `3` discards the older `2`. The candidates are now indices `[0, 2]` with values `[4, 3]`, so the first maximum is `4`. On the next step, index 0 expires. The candidates become `[2, 3]`, with values `[3, 1]`, so the second maximum is `3`.

<Tabs items={["JavaScript", "Python"]}>
  <Tab value="JavaScript">
    ```js
    function maxSlidingWindow(nums, k) {
      const entries = {};
      let front = 0;
      let back = 0;
      const result = [];
    
      for (let index = 0; index < nums.length; index++) {
        while (front < back && entries[front] <= index - k) {
          delete entries[front];
          front++;
        }
    
        while (
          front < back &&
          nums[entries[back - 1]] <= nums[index]
        ) {
          back--;
          delete entries[back];
        }
    
        entries[back] = index;
        back++;
    
        if (index >= k - 1) {
          result.push(nums[entries[front]]);
        }
      }
    
      return result;
    }
    ```
  </Tab>
  <Tab value="Python">
    ```python
    from collections import deque
    
    
    def max_sliding_window(nums, k):
        indices = deque()
        result = []
    
        for index, value in enumerate(nums):
            while indices and indices[0] <= index - k:
                indices.popleft()
    
            while indices and nums[indices[-1]] <= value:
                indices.pop()
    
            indices.append(index)
    
            if index >= k - 1:
                result.append(nums[indices[0]])
    
        return result
    ```

### Big O notation

| Measure | Complexity | Explanation |
|---|---:|---|
| Time | `O(n)` | Each index enters and leaves the deque at most once. |
| Auxiliary space | `O(k)` | At most `k` candidate indices are live. The returned array separately holds `n - k + 1` maxima. |
