## Try It Yourself

Remove a node counted from the end without measuring the list first. `n = 1` means remove the tail. Return the head of the remaining list.

Submit your implementation when it passes the examples. The removed node may be the head, the tail, or the only node.

## Solution

![With fast just past node 60 and slow at 40, slow.next is 50, the second node from the end.](https://pub-d143c03df8bc45d5a4589bc793aa52e4.r2.dev/courses/03ce588b-f581-46ee-b98b-277331400e55/gallery/3fd86748-4a2e-4511-a15b-5bd7da84bc8c)

Start `slow` at a dummy node just before the head and `fast` at the head. Advance `fast` by `n` links, then move both pointers together until `fast` reaches `null`. Throughout the paired walk, `fast` is `n` links ahead of `slow.next`.

In the diagram, `n = 2`. From node 50 it takes two links to reach `null`, through 60. When `fast` reaches `null`, `slow` points to 40, so link 40 directly to 60. If `n` equals the entire list length, `slow` stays at the dummy and the same update removes the head.

<Tabs items={["JavaScript", "Python"]}>
  <Tab value="JavaScript">
    ```js
    function removeNthFromEnd(head, n) {
      const dummy = { val: 0, next: head };
      let fast = head;
      let slow = dummy;
    
      for (let step = 0; step < n; step++) {
        fast = fast.next;
      }
    
      while (fast !== null) {
        fast = fast.next;
        slow = slow.next;
      }
    
      slow.next = slow.next.next;
      return dummy.next;
    }
    ```
  </Tab>
  <Tab value="Python">
    ```python
    def remove_nth_from_end(head, n):
        class Dummy:
            def __init__(self, next_node):
                self.val = 0
                self.next = next_node
    
        dummy = Dummy(head)
        fast = head
        slow = dummy
    
        for _ in range(n):
            fast = fast.next
    
        while fast is not None:
            fast = fast.next
            slow = slow.next
    
        slow.next = slow.next.next
        return dummy.next
    ```
  </Tab>
</Tabs>

### Big O notation

| Measure | Complexity | Explanation |
|---|---:|---|
| Time | `O(L)` | For a list of length `L`, each pointer advances at most `L` times. The input `n` specifies the position counted from the end. |
| Auxiliary space | `O(1)` | The algorithm uses one dummy node and two pointers. |
