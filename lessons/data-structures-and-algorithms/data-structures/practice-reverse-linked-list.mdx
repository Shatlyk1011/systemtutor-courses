## Solution

![The current node 2 redirects its next link to 1 while a saved reference to 3 preserves the rest of the list.](https://pub-d143c03df8bc45d5a4589bc793aa52e4.r2.dev/courses/03ce588b-f581-46ee-b98b-277331400e55/gallery/8407272a-b445-4cc8-9ba4-75ab4b7ccc06)

`previous` heads the part already reversed. `current` heads the part still to visit. On `1 → 2 → 3`, save the link to 2 before pointing `1.next` to `null`. Now `previous` is 1 and `current` is 2, so both pieces remain reachable. Repeat the same four assignments for each remaining node.

When current reaches null, previous points to the original tail, which is now the new head.

<Tabs items={["JavaScript", "Python"]}>
  <Tab value="JavaScript">
    ```js
    function reverseList(head) {
      let previous = null;
      let current = head;
    
      while (current !== null) {
        const next = current.next;
        current.next = previous;
        previous = current;
        current = next;
      }
    
      return previous;
    }
    ```
  </Tab>
  <Tab value="Python">
    ```python
    def reverse_list(head):
        previous = None
        current = head
    
        while current is not None:
            next_node = current.next
            current.next = previous
            previous = current
            current = next_node
    
        return previous
    ```
  </Tab>
</Tabs>

### Big O notation

| Measure | Complexity | Explanation |
|---|---:|---|
| Time | `O(n)` | Every node is visited and rewired exactly once. |
| Auxiliary space | `O(1)` | The reversal uses three node references regardless of list length. |
