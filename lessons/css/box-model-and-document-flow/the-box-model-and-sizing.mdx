---
title: "The Box Model and Sizing"
description: "See every element as a box, inspect its layers, and use width, height, padding, borders, and margins to control its space."
---

Every visible part of a page—text, images, icons, and links—has a box that the browser can place alongside other boxes. Think of building a page as arranging boxes and putting smaller boxes inside larger ones. That mental model gives you a place to start when something looks too large, too close to its neighbor, or too close to its own edge.

## See the boxes in a page

Imagine a page with a header and an article:

```text
Page
├── Header
│   ├── Logo icon
│   └── Home link
└── Article
    ├── Title
    ├── Image
    └── Paragraph
```

Each item has its own box. The header and article are also boxes that contain other boxes. This nesting explains the page's structure: to understand where the Home link sits, first find the header that contains it.

### Inspect a box in the browser

The browser's inspector makes these otherwise invisible areas easier to see:

1. Open the inspector and select an element on the page or in its element list.
2. Look at the highlight over that element. It shows the selected box and visualizes its layers.
3. Select a different element, such as a paragraph or button, and compare the highlighted areas.

Try selecting a header, a paragraph, and a button. As you move between them, notice which highlighted area belongs to the content and which areas surround it. The inspector helps you identify the particular box involved in a layout problem.

## Read the box from the inside out

An element's box has four layers:

```text
margin
└── border
    └── padding
        └── content
```

The **content box** is the area for the element's actual content, such as text or an image. **Padding** is space inside the border, between that content area and the edge. Think of the mat between a picture and its frame. The **border** draws the edge around the content and padding. **Margin** is space outside that border, separating the element from its surroundings.

These layers answer different questions. If text feels crowded against a card's edge, change the padding. If the card needs a visible edge, change the border. If the card sits too close to another element, change the margin.

## Set the content area's size

`width` sets the content box's horizontal size, and `height` sets its vertical size in the default content-box sizing model. For example:

```css
.card {
  width: 240px;
  height: 120px;
}
```

This gives the card a content area 240 pixels wide and 120 pixels tall. The dimensions describe the content area; space added around it belongs to the other box layers.

## Add space and an edge

Add padding to move the content away from the border, a border to draw the edge, and margin to separate the card from nearby boxes:

```css
.card {
  width: 240px;
  height: 120px;
  padding: 16px;
  border: 2px solid green;
  margin: 24px;
}
```

Read the border declaration as **thickness**, **style**, and **color**: `2px` is the thickness, `solid` is the line style, and `green` is its color. Padding places 16 pixels of space between the content and border on every side. Margin adds 24 pixels of outside space on every side.

With this content-box sizing, the border-box width is `240px + 16px + 16px + 2px + 2px = 276px`. The height works the same way: `120px + 16px + 16px + 2px + 2px = 156px`. Margin sits beyond those dimensions. Increasing padding or border thickness can therefore make the whole box take up more room, even when `width` and `height` stay the same.

### Change one border side

Use a side-specific border when one edge needs different treatment:

```css
.card {
  border: 2px solid green;
  border-top: 4px solid green;
  border-left: 2px dashed purple;
}
```

The first declaration sets all four sides. The next two replace only the top and left borders. You can also set `border-right` and `border-bottom` independently.

## Choose the layer to change

Suppose a card's text nearly touches its border, while the card itself nearly touches a neighboring card. Those are two separate gaps. Increase **padding** for the gap inside the border, then adjust **margin** for the gap outside it. Changing the border's thickness or style changes the edge rather than serving either spacing job.

Use the inspector to check your choice: select the card and look for the highlighted area that corresponds to the gap you want to change. The content, padding, border, and margin appear in that order from the center outward.

Before moving on, decide which property you would use in each case:

1. Make the text farther from the card's edge.
2. Draw a thicker line only along the card's top edge.
3. Put more space between the card and its neighbor.

The answers are `padding`, `border-top`, and `margin`, respectively. Each changes a different layer of the same box.

## Key Takeaways

- **Boxes:** The browser arranges elements as boxes that can sit inside other boxes.
- **Layers:** Content, padding, border, and margin run from the inside outward.
- **Sizing:** `width` and `height` set the content area in the default content-box model; padding and borders add to its outer size.
- **Spacing:** Padding separates content from the border, while margin adds space outside the border.
- **Inspection:** The browser's inspector highlights a selected element and helps identify its box layers.
