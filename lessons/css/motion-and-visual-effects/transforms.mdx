A **transform** changes how an element is drawn: it can move, turn, grow, shrink, or slant. A transform alone is immediate. A transition or animation can make that transformation change over time.

## Learn the main 2D operations

| Function | Example | Visual result |
| --- | --- | --- |
| `translate()` | `translate(12px, -4px)` | Moves right 12 pixels and up 4 pixels. |
| `rotate()` | `rotate(8deg)` | Turns the element by an angle. |
| `scale()` | `scale(1.1)` | Draws it at 110% of its size. |
| `skewX()` | `skewX(10deg)` | Slants it along the horizontal axis. |

`translateX()` and `translateY()` change one axis. `scaleX()` and `scaleY()` scale one axis. A scale of `1` preserves size; `0.8` draws at 80%.

The Popular tag appears raised and tilted, but neighboring tags are laid out using its original box. A transform does not make siblings rearrange around the transformed shape. Leave enough space to prevent overlap or clipping.

`inline-block` lets these text spans use transforms. An ordinary inline text box cannot be transformed.

## Choose the pivot point

For these HTML elements, the default transform origin is the center. Changing it alters the pivot used by rotation and scaling:

```css
/* [!code word:transform-origin] */
.status-tag--raised {
  transform-origin: left center;
  transform: rotate(-8deg);
}
```

Use this rule instead of the earlier raised-tag rule. The tag now pivots around the middle of its left edge. `transform-origin` does not add another movement; it changes the reference point for the transformation.

## Keep function order intentional

These declarations produce different positions:

```css
.first {
  transform: translateX(40px) rotate(90deg);
}

.second {
  transform: rotate(90deg) translateX(40px);
}
```

In the first, the shift follows the original horizontal direction. In the second, it follows the rotated direction. Changing the function order changes the result.

A new `transform` value replaces the old list of functions. To scale an already rotated element on hover, include both `rotate()` and `scale()` in the hover rule.

These examples are static transformations, so they introduce no movement over time. When animating them, use the reduced-motion handling taught later in this chapter.

## Key Takeaways

- **Operations:** Translate, rotate, scale, and skew change the rendered shape or position.
- **Layout:** A transformed element keeps its original place in normal layout.
- **Origin:** Choose the pivot for rotation and scaling with `transform-origin`.
- **Composition:** Function order matters, and a new transform declaration replaces the old list.
