CSS controls how a browser presents HTML. A single button is enough to see its three main decisions at work. A selector chooses the button, the cascade decides which rules win, and layout determines how much space the button takes.

## A path through the course

1. [Connect a stylesheet to HTML](/courses/css/docs/css-foundations/getting-started-with-css), then use the browser’s inspector to see which declarations apply.
2. [Resolve competing rules](/courses/css/docs/selectors-and-the-cascade/resolving-style-conflicts) and use custom properties to share colors and spacing.
3. [Measure the box model](/courses/css/docs/box-model-and-document-flow/the-box-model-and-sizing). Predict how padding and borders affect a component’s width.
4. Arrange a row of controls with [Flexbox](/courses/css/docs/flexbox-layouts/flexbox), then use [Grid](/courses/css/docs/grid-layouts/grid-fundamentals) when rows and columns need to align.

Try the [primary button challenge](/practice/css/primary-button) to apply these ideas. Compare the result with the target and adjust one property at a time. Later modules cover responsive layouts, forms, keyboard focus, motion preferences, and testing.

When you encounter an unfamiliar property, look up its syntax and accepted values in the [MDN CSS reference](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference).
