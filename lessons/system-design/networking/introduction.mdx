A browser asks a server for a page. The browser knows which page it wants. The router in your home only needs enough information to send the packet one step closer to its destination. Dividing the work this way allows the same browser request to travel over Wi-Fi or Ethernet.

## Follow the request down the stack

Suppose the browser uses HTTP/1.1 over TCP. Each layer adds the information its peer will need to interpret the data. This process is called **encapsulation**.

| Layer | What it contributes to this request |
|---|---|
| Application | HTTP expresses an operation such as `GET /users/42`. |
| Transport | TCP identifies the connection and tracks the order of its bytes. |
| Internet | IP adds addresses that routers use to forward packets toward the destination. |
| Link | Wi-Fi or Ethernet delivers a frame across the current local link. |

![As application data travels down the stack, transport, IP, and link headers are added for delivery.](https://pub-d143c03df8bc45d5a4589bc793aa52e4.r2.dev/courses/54de4736-cbfb-4ca3-add4-542a111f11df/gallery/ad8e566d-e48a-4cef-8c98-764718d7bc7b)

A switch can forward the frame within a local network. A router receives the packet and forwards it on another link, using a new frame for that hop. At the destination, IP delivers the payload to TCP. TCP makes the ordered bytes available to the server, which can then read the HTTP request.

This four-layer grouping describes the Internet protocol suite. You may also encounter the seven-layer **OSI model**. Its session, presentation, and application layers fit roughly into the application row above. Its data-link and physical layers fit into the link row.

## Measure waiting and completed work

**Round-trip time (RTT)** measures how long a signal takes to reach a peer and receive a reply. **Throughput** measures work completed per unit of time, such as bytes delivered per second. If a client needs two sequential exchanges on a path with a 40 ms RTT, it spends about 80 ms on round trips alone, before adding processing or transfer time. More bandwidth can help with a large response, while the client still has to wait for each dependent reply.

## Key Takeaways

- **Layers** divide a request into application meaning, transport, routing, and local delivery.
- **Encapsulation** adds each layer’s metadata on the sender and lets the receiver recover the original message.
- **Round trips** add waiting time. Throughput describes how much data or work finishes in an interval.
