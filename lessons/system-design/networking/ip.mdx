**Before you begin** — [How a request crosses a network](/courses/system-design/docs/networking/introduction).

When your laptop requests a page, it sends packets toward the service’s **Internet Protocol (IP) address**. Each router uses the destination address to choose a next hop. The address identifies a network interface in a particular network context. A device can have several addresses, and an address can be reassigned.

## Read an address

| Version | Size | Example | How to read it |
|---|---|---|---|
| IPv4 | 32 bits | `192.0.2.1` | Four decimal numbers separated by dots. Each number represents eight bits and ranges from 0 to 255. |
| IPv6 | 128 bits | `2001:db8::1` | Groups of hexadecimal digits separated by colons. A double colon can stand for a run of zero groups. |

IPv4 has about 4.3 billion possible addresses. IPv6 provides a much larger address space. Both protocols carry packets with a source and destination address.

## Follow a packet out of a private network

A phone and a laptop on your home network can have different **private IPv4 addresses**. Another home can reuse those same addresses because Internet routers do not forward traffic to private ranges across the public Internet.

![Several private devices access the internet through a router with one public IP address.](https://pub-d143c03df8bc45d5a4589bc793aa52e4.r2.dev/courses/e25a97c7-7bb0-4a6e-a419-05a6f6f3c1fa/gallery/3deb6b01-5261-46f5-9cb7-68140f5594eb)

1. The laptop sends a packet addressed to a public service. On the home network its source is its private address.
2. The home router performs **network address translation (NAT)**. In a common home setup, it substitutes a public source address and keeps a mapping that includes transport ports. Connections from several devices can now share that public address.
3. The service replies to the translated address and port. The router uses the mapping to forward the reply to the laptop.

A public address can be routed on the Internet. Whether a client can actually reach a service at that address also depends on routing and firewall rules.

## Separate scope from assignment

**Public** and **private** describe where an address is usable. **Static** and **dynamic** describe how the address is assigned. A private database address can be static. A router’s public address can be dynamically assigned and may change. Dynamic assignment does not require the address to change at every renewal.

## Deliver the payload to the right program

An IP header identifies the source, destination, and the protocol carried inside. For a web request using TCP, IP routes the packets to the host, and TCP uses connection information including ports to deliver the bytes to the right endpoint. The server can then interpret the HTTP message.

## Key Takeaways

- **Addresses** let routers forward packets toward a destination within the appropriate network scope.
- **NAT** lets devices share a public IPv4 address by tracking translations for their traffic.
- **Ports** help the destination’s transport layer deliver incoming data to the right endpoint.
