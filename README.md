# SystemTutor lessons

This repository contains the lesson source and course navigation for SystemTutor. Lessons are in `lessons/`, grouped by course and chapter.

Found an error? Open an issue or edit the relevant `.mdx` file and open a pull request. See [CONTRIBUTING.md](CONTRIBUTING.md) for details.

The website uses a reviewed snapshot of this repository; changes appear on the site after they are synced and deployed. Quiz and practice files can refer to content maintained in the application, so please report issues with those parts.
