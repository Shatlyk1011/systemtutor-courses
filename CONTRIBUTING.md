# Contributing

1. Find the lesson under `lessons/` and use GitHub's edit button, or fork and clone the repository.
2. Make a focused correction and preserve existing frontmatter, MDX components, and navigation unless your change requires otherwise.
3. Open a pull request describing the problem and your change. Include reliable references for factual corrections when useful.

For quiz or interactive exercise problems that are not defined in these lesson files, please open an issue with the lesson URL and details. A maintainer reviews contributions and applies accepted changes to the private application source before updating this public copy.

MDX can contain executable code; submit text and examples only unless a maintainer requests a component change.
